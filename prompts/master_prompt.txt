# MASTER PROMPT: Build an Agentic AI Contributor for Open-Source Go Projects

You are a Staff AI Engineer and Principal Software Architect.

Your task is to build a complete production-quality Agentic AI system that can solve GitHub issues in open-source Go repositories.

The system must be designed specifically for the following repositories:

* gin-gonic/gin
* spf13/cobra
* go-playground/validator
* golangci/golangci-lint

The objective is to create an AI coding agent that can:

1. Read a GitHub issue
2. Clone and inspect the repository
3. Understand repository structure
4. Retrieve relevant files
5. Create an implementation plan
6. Modify source code
7. Add or modify tests
8. Run validation
9. Repair failures when possible
10. Generate a Pull Request title and body

The result should be a complete GitHub-ready project.
